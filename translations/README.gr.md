# Dustcode

Το Dustcode είναι ένας πράκτορας προγραμματισμού AI ανοικτού κώδικα αποκλειστικά για το **VS Code**. Αυτό το fork συντηρεί μόνο την επέκταση και το ενσωματωμένο backend, χωρίς ξεχωριστό CLI, πρόσθετο JetBrains ή προϊόν cloud.

## Εγκατάσταση

1. Εκτελέστε `bun run build:vscode` στη ρίζα του αποθετηρίου ή κατεβάστε το artifact της πλατφόρμας σας από μια επιτυχημένη εκτέλεση **VS Code** στο GitHub Actions αυτού του αποθετηρίου.
2. Αποσυμπιέστε το artifact αν χρειάζεται και επιλέξτε το `dustcode-<target>.vsix` μέσω **Extensions: Install from VSIX...** στο VS Code.
3. Ανοίξτε το Dustcode και ρυθμίστε ξεχωριστά έναν πάροχο μοντέλων.

Το ID της επέκτασης είναι `dustcode.dustcode`, οι ρυθμίσεις χρησιμοποιούν `dustcode.*` και η κατάσταση έργου βρίσκεται στο `.dustcode/`. Δεν εισάγονται διαπιστευτήρια ή συνεδρίες του Kilo Code. Δεν έχει ρυθμιστεί αυτόματη δημοσίευση ή επιβεβαιωμένη σελίδα Dustcode στο Marketplace.

Το [κύριο README](../README.md) είναι η βασική αναφορά για ρυθμίσεις και ανάπτυξη. Για builds VSIX και artifacts CI δείτε το [RELEASING.md](../RELEASING.md).
