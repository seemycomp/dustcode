# Dustcode

Dustcode является AI-агентом для программирования с открытым исходным кодом только для **VS Code**. Этот форк поддерживает лишь расширение и встроенный backend, не выпуская отдельный CLI, плагин JetBrains или облачный продукт.

## Установка

1. Выполните `bun run build:vscode` в корне репозитория или скачайте артефакт для своей платформы из успешного запуска **VS Code** в GitHub Actions этого репозитория.
2. При необходимости распакуйте артефакт и выберите `dustcode-<target>.vsix` командой **Extensions: Install from VSIX...** в VS Code.
3. Откройте Dustcode и отдельно настройте поставщика моделей.

ID расширения: `dustcode.dustcode`. Настройки используют `dustcode.*`, состояние проекта хранится в `.dustcode/`. Данные входа и сессии Kilo Code не импортируются. Автоматическая публикация и подтверждённая страница Dustcode в Marketplace не настроены.

[Корневой README](../README.md) содержит актуальные сведения о настройке и разработке. Сборка VSIX и артефакты CI описаны в [RELEASING.md](../RELEASING.md).
