# Dustcode

Dustcode є агентом програмування зі ШІ та відкритим кодом лише для **VS Code**. Цей форк підтримує тільки розширення та вбудований backend, не випускаючи окремий CLI, плагін JetBrains чи хмарний продукт.

## Встановлення

1. Виконайте `bun run build:vscode` у корені репозиторію або завантажте артефакт для своєї платформи з успішного запуску **VS Code** у GitHub Actions цього репозиторію.
2. За потреби розпакуйте артефакт і виберіть `dustcode-<target>.vsix` командою **Extensions: Install from VSIX...** у VS Code.
3. Відкрийте Dustcode та окремо налаштуйте постачальника моделей.

ID розширення: `dustcode.dustcode`. Налаштування використовують `dustcode.*`, стан проєкту зберігається в `.dustcode/`. Дані входу та сесії Kilo Code не імпортуються. Автоматичне оприлюднення та підтверджена сторінка Dustcode у Marketplace не налаштовані.

[Кореневий README](../README.md) містить основні відомості про налаштування та розробку. Збірки VSIX і артефакти CI описано в [RELEASING.md](../RELEASING.md).
